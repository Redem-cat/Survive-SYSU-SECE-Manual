# 神经网络与深度学习

::: tip 课程简介与重要性
神经网络与深度学习是人工智能的核心技术，在计算机视觉、自然语言处理等领域有广泛应用。
:::

::: info 学习难度与前置知识
- **难度等级**：⭐⭐⭐⭐
- **前置知识**：概率论、线性代数、Python编程
- **学习建议**：张瑞茂老师授课，英语课件和试卷
:::

::: tip 课程特点
- 张瑞茂老师讲课用心
- 涉及到的知识领域全面
- 采用英语课件和试卷
- 复习只需要看老师给的总结课件即可得到一个还算不错的分数
- 比较推荐

::: details 推荐教材
- **《深度学习》（花书）**
  - 优点：内容全面权威
  - 缺点：数学要求高
  - 使用建议：作为深入学习的参考

- **《动手学深度学习》**
  - 优点：代码实践丰富
  - 缺点：理论深度有限
  - 使用建议：适合边学边练
:::

::: tip 考试重点与备考策略
**考试重点**：
- 神经网络基础
- 卷积神经网络（CNN）
- 循环神经网络（RNN）
- 深度学习优化
- 常用深度学习框架

**备考策略**：
1. 认真听课，理解核心概念
2. 重点复习老师给的总结课件
3. 掌握常用网络结构
4. 完成实验和编程作业
