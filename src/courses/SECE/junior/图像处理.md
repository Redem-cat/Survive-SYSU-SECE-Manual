# 图像处理

::: tip 课程简介与重要性
图像处理研究数字图像的分析、处理和理解，在计算机视觉、医学影像、安防监控等领域有重要应用。
:::

::: info 学习难度与前置知识
- **难度等级**：⭐⭐⭐⭐
- **前置知识**：信号与系统、概率论
- **学习建议**：是一些学校的研究生课，但在我院是本科生课
:::

::: tip 课程特点
- 老师讲课有点快
- 题目相对来说不算很难
- 会从平时作业里面抽一些题型来考察
- 可以将复习重点放在平时作业

::: warning 重要提示
很关键的一点是它还会考察上课时雨课堂用到的题目，会考一些非常容易混淆的概念性题目，容易在这方面丢分。
