# 电磁场与电磁波

::: tip 课程简介与重要性
电磁场与电磁波是电子工程专业的核心课程，研究电磁场的运动规律和电磁波的传播特性。这门课程与物理相关专业"四大力学"中的"电动力学"类似，不过电动力学是四大力学里面最简单的。
:::

::: info 学习难度与前置知识
- **难度等级**：⭐⭐⭐⭐⭐
- **前置知识**：大学物理、高等数学、线性代数
- **学习建议**：相对较难，需要扎实的数学基础
:::

::: tip 考试重点与备考策略
**考试重点**：
- 麦克斯韦方程组
- 静态场分析
- 时变电磁场
- 平面电磁波传播
- 导波与传输线

**备考策略**：
1. 理解麦克斯韦方程组的物理意义
2. 掌握边界条件求解方法
3. 重点复习平面波的传播特性
4. 多做计算题
