# 信息论与编码

::: tip 课程简介与重要性
信息论与编码研究信息的表示、传输和处理的理论基础，是通信领域的核心课程。
:::

::: info 学习难度与前置知识
- **难度等级**：⭐⭐⭐⭐
- **前置知识**：概率论、随机过程
- **学习建议**：老师打分相对严格，题型固定但需大量练习
:::

::: warning 课程特点
- 几乎所有试题都是基于之前的作业和课上讲解的题型
- 书上的一些关键概念会考察填空
- 老师打分相对严格
- 题型虽然相对固定但仍需大量时间练习

::: tip 考试重点与备考策略
**考试重点**：
- 熵与信息量
- 信源编码
- 信道容量
- 信道编码
- 纠错码

**备考策略**：
1. 认真做作业，考试基于作业题型
2. 背诵书本关键概念，应对填空题
3. 多做练习，熟练掌握各种编码方法
4. 注意计算细节
