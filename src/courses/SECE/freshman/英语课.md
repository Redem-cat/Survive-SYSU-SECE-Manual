# 英语课

::: info 课程简介
作为工科学生，未来的学习中除了一些专业词汇外，很少会用到英语口语和写作，阅读英语的情况也相对较少。在科研中偶尔会涉及，但主要是对行业专有名词的了解。
:::

::: tip 学习建议
- 学校的英语课不会大幅提升英语水平，但可能延缓英语能力退步
- **强烈建议在大一考完四六级**，之后学习和使用英语的时间会越来越少
- 四六级主要特点：听力特别快、题量较大，需要特别练习
- 东一教学楼有声自习室适合练习雅思托福口语和听力
:::

::: details 推荐学习资源
- **四六级备考**：
  - 真题集是核心，反复练习
  - 重点突破听力和阅读

- **雅思托福**（如需出国）：
  - 东一教学楼有声自习室提供练习场所
  - 根据目标院校要求提前准备
:::

::: note 其他语言选择
如果有特殊兴趣，也可以选择自学日语到N2/N1水平去日本留学EE相关专业：
- 学校日语课教授五十音及基础词汇
- 日本在电子领域仍有较大影响力
- 如果不想太卷，去日本留学是不错的选择
:::
