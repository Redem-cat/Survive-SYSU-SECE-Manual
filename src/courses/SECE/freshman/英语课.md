# 英语课
作为工科，未来的学习中其实除了一些专业词汇很少会用到英语口语和写作，甚至不怎么会用到英语的阅读。在科研中偶尔会涉及到一些，但这方面也主要是对行业专有名词的了解。

另外学校的英语课一般来说不会提升太多你的英语水平，但是也许能延缓你英语水平退步的速度。建议多数同学尽量在大一考完四六级，不然后面用来学英语和用到英语的时间都会变得越来越少。考四六级主要特点是听力特别快，以及题量较大，需要特别练习。

东一教学楼有部分小教室是有声自习室，如果要考雅思托福等可以在里面练习口语或者听力。

另外如果有特别的兴趣，你也可以选择自学日语到N2 N1去日本学EE相关专业，学校开展的日语课会教你五十音以及一些非常基本的词汇，如果不愿意太卷去日本留学也是不错的选择，日本虽然前沿科技相对落后了但是在电子领域还是有着相当大的影响力。
