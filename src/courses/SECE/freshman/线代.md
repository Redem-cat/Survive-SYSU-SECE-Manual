# 线性代数

::: tip 课程简介与重要性
线性代数是研究线性空间和线性变换的数学学科，内容抽象但实用。它是计算机图形学、机器学习、信号处理等领域的重要基础。虽然刚学时觉得抽象，但掌握后会发现它在工程技术中应用广泛。
:::

::: info 学习难度与前置知识
- **难度等级**：⭐⭐⭐
- **前置知识**：高中代数基础
- **学习建议**：概念性内容居多，重在理解线性运算的本质
:::

::: details 推荐教材
- **同济大学《工程数学·线性代数》（第六版）**

  - 优点：讲解深入，实例丰富
  - 缺点：内容较多，学习周期长
  - 使用建议：适合深入学习理解
:::

::: tip 考试重点与备考策略
**考试重点**：
- 行列式计算与性质
- 矩阵运算与逆矩阵
- 线性方程组解的结构
- 特征值与特征向量
- 二次型及其标准化

**备考策略**：
1. 熟练掌握基本计算方法
2. 理解概念之间的联系
3. 多做证明题，提高逻辑思维
:::
