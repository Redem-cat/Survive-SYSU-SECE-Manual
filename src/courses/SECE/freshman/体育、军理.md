# 体育、军理

## 体育课

::: tip 选课建议
体育课方面建议多选一些有意思的课以及自己擅长的课：
- 有意思的课：可以了解更多运动途径
- 擅长的课：提供较为稳定的体验
:::

::: info 关于热门课程
一般来说有一些较为热门的课程比较难抢到：
- 如果没抢到，开学后可以和授课老师商量
- 提交申请到体育部转到想去的那门课上
- 也可以选择运动量充足的课程，提升自身体质

## 军理课

::: tip 课程简介
军事理论课是大学必修课程，内容包括国防理论、军事思想、军事科技等。
:::

::: warning 考试注意事项
军理课和思政课类似：
- 上课去不去不是那么重要
- **但是考试占比确实不小**，请多花些时间在应试上，推荐买一下教材，考试大题全是课后思考题，而选择题有单选和多选考的很细，可以看看以往真题然后多翻翻书
