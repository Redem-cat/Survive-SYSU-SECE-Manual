# 电路理论基础

::: tip 课程简介与重要性

课程难度不大，但是可以为之后的模电数电打下基础，实验课多熟悉一下示波器等仪器

:::

::: info 学习难度与前置知识

- **难度等级**：⭐⭐
- **前置知识**：高中的电路知识即可
- **学习建议**：建议多计算，然后注意一下理解概念和原本
:::

**考试重点**：考察重点是计算，也会考察一些概念，但总体都很简单
