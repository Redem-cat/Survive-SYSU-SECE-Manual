# 大学物理

::: tip 课程简介与重要性
大学物理是工科学生的基础必修课，涵盖力学、热学、电磁学、光学和近代物理等内容。它不仅是理解工程现象的基础，也为后续专业课如电磁场、信号处理等提供物理基础。
:::

::: info 学习难度与前置知识

- **难度等级**：⭐⭐⭐⭐
- **前置知识**：高中物理基础、高数微积分基础
- **学习建议**：理论推导与实验结合，注意物理图像的建立
  :::

::: details 推荐教材

- **程守洙《普通物理学》**

  - 优点：国内经典教材，内容全面
  - 缺点：部分内容较为陈旧
  - 使用建议：作为主教材学习
- **Halliday《物理学基础》**

  - 优点：讲解生动，例题丰富
  - 缺点：与国内考试要求有差异
  - 使用建议：适合理解物理概念
    :::

::: tip 考试重点与备考策略
**考试重点**：

- 力学：牛顿定律、能量守恒、刚体转动
- 热学：热力学定律、分子动理论
- 电磁学：电场、磁场、电磁感应
- 光学：波动光学、几何光学
- 近代物理：量子物理初步

**备考策略**：

1. 掌握基本公式和定律
2. 重视实验课内容
3. 多做典型例题
   :::
