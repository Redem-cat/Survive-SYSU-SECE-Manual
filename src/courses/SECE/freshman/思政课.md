# 思政课

::: tip 课程简介
思政课是大学必修课程系列，包括马克思主义基本原理概论、毛泽东思想和中国特色社会主义理论体系概论、思想道德与法治、中国近现代史纲要等课程。
:::

::: info 学习难度与特点

- **难度等级**：⭐⭐
- **课程特点**：理论性强，需要记忆内容较多
  :::

::: tip 考试重点与备考策略
**两句话总结**：**背多分，写多分**

- 多背多写更有概率拿到较好的分数
- 期末考试通常有一张甚至两张答卷

**学习建议**：

- 上课可以当作自习时间
- 也可以选择和老师多互动，留下好印象
- 期末复习重点在于记忆和理解
  :::
