# 公选课

::: tip 课程简介
这里将会贴出一份往届学长学姐（并非本指南）总结出的公选课推荐作为参考，那些成名已久的公选课往往都有其特色。
:::

:::

::: info 选课策略建议
根据不同目标，选课策略有所不同：

**对于可能会出国留学或正在犹豫留学的同学**：
- 需要尽可能选择得分较高的课程
- 如果没抢到这类课程，不必急着修满公选学分
- 到需要刷分的时候再选择

**对于计划本科就业的同学**：
- 确实需要尽早修完公选学分
- 不必在意课程的给分，凭自身规划选择即可

**对于打算保研的同学**：
- 本院保研在绩点方面只看必修课和专业选修课（大二才有）
- 公选课凭自身规划选择即可
- 早点修完未来可以提前进组

**对于计划考研的同学**：
- 其实并不一定需要早点修完学分
- 考研途中不时上课放松一下也是一种选择
- 可以大四下再修公选

**通用建议**：
- 大一大二时同学们往往会着急修满公选学分而紧张抢课
- 特别是公共艺术课非常难选
- 实则如果你没有特别的打算，提前修满公选学分这个选择并不一定有想象中那么好
- 大四特别是大四下的时候公选课简直是点击就送
- 有时候一些比赛或者奖项会直接给你公选学分
