# 工程制图

::: tip 课程简介与重要性
工程制图是一门技术基础课，培养学生的绘图能力和空间想象能力。通过学习掌握工程图样的绘制方法和识图能力。
:::

::: info 学习难度与前置知识
- **难度等级**：⭐⭐
- **前置知识**：几何基础
- **学习建议**：多画多练，培养空间想象能力
:::

::: info 课程特点
画画课，挺好玩的。平常认真听就行，会经常有课堂题目。

::: warning 考试重点与备考策略
期末题目不算太难，但是题量很多，可能会有一半的人写不完。

**备考策略**：
1. 重视课堂练习
2. 提高绘图速度
3. 熟悉常用绘图技巧
4. 注意时间分配
