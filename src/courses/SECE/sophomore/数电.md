# 数字电子技术

::: tip 课程简介与重要性
数字电子技术（数电）是电子工程和计算机科学的基础课程，主要研究数字电路的设计与分析。相比于模拟电子技术，数电更加实用，是嵌入式开发、计算机硬件设计的核心基础。
:::

::: info 学习难度与前置知识
- **难度等级**：⭐⭐⭐
- **前置知识**：程序设计（C/C++）、基本逻辑思维
- **学习建议**：比模电简单，多做练习题，熟悉逻辑电路设计
:::

::: warning 课程特点
- 老师会使用英语课件
- 经常抽人上黑板写题目
- 如果想做嵌入式方向，数电比模电更实用

::: tip 考试重点与备考策略
**考试重点**：
- 数制转换与编码
- 逻辑代数基础
- 逻辑函数化简
- 组合逻辑电路设计
- 时序逻辑电路设计
- 常用集成电路应用

**备考策略**：
1. 掌握数制转换方法
2. 熟练运用逻辑代数化简
3. 理解组合和时序电路的区别
4. 多做课后习题
