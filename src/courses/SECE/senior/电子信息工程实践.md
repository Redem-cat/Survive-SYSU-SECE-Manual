# 电子信息工程实践

::: tip 课程简介与重要性
电子信息工程实践是大四的实践性课程，通过团队项目形式培养学生的综合实践能力。
:::

::: info 学习难度与前置知识
- **难度等级**：⭐⭐⭐
- **前置知识**：专业知识综合
- **学习建议**：尽早组队和选题
:::

::: tip 课程流程
这门课不是实验课但也是偏向于实践的一门课，是：
1. 小组组队
2. 找老师选题
3. 完成选题所要求的项目
4. 与选题老师沟通结题
5. 评审

一般说来除了第一次以外不要求去教室和实验室上课，如果你的选修课学分已经修满的话你们大四就只剩这一门课了。

::: warning 重要提示
尽早组队和选题，动作慢的话好的选题都被选完了。
